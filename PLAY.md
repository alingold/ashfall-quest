# Play ASHFALL on a Meta Quest

**Download:** `AshfallUnityQuest-1.3.10-playtest-r11.apk` (2.4 GB) from the shared Google Drive
folder **ASHFALL** (link: DRIVE_LINK_PENDING).

The APK is not on the Meta store, so it is installed ("sideloaded") from a computer:

1. **Turn on developer mode once.** In the Meta Horizon phone app: Menu → Devices → your headset →
   Headset settings → Developer mode → On. (You may first need to create a free developer
   organization at developer.oculus.com.) Restart the headset.
2. **Connect the headset to the computer with a USB-C cable.** Put it on and accept
   "Allow USB debugging" (tick "Always allow").
3. **Install the APK** with either:
   - **SideQuest** (easiest, sidequestvr.com): drag the `.apk` onto the SideQuest window, or
   - **adb** (Android platform tools): `adb install -r AshfallUnityQuest-1.3.10-playtest-r11.apk`
4. On the headset: **Library → Unknown sources → ASHFALL Unity Quest**.

Version 1.3.10-playtest-r11 (Android version code 20). Multiplayer needs everyone on this same
version.
