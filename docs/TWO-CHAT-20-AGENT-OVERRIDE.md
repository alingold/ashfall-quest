# Campaign ownership and admission

Follow [R24 working rules](HILL-CLIMB-ORCHESTRATION.md).

- Skins: editable models, PCVR/LIGHT exports and reference comparisons; isolated staging.
- WORLD/Maps: Godot R24 integration, maps, UI, audio, Quest builds and device operations.
- Unity: runnable Unity feature slices and their builds.

The user allocated up to twenty workers per chat. Use them for substantive, disjoint implementation; do not maintain twenty busy slots through review refills. Leaves do not spawn grandchildren. Keep the requested model/provider settings and existing spending limits.

GPU/Blender work and engine/device work remain separately serialized. Shared originals have one writer. No mass cache/pack copies per worker. Current baseline is Opus R23 → `quest-r24/source`, not `quest-r22/source`.
