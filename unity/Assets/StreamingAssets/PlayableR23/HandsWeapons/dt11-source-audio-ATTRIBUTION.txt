DT11 blast is the original authored procedural cue from scripts/shotgun.gd::_bake_cue("blast") in Ashfall frozen R6 (manifest b62578d419897f741f119eec885d199dc966824a21452bc60326d54a23e01111). It is not a recorded external game sound. Its deterministic PCG32/math recipe is ported offline at32000Hz/16bit/20800samples. No Godot renderer/audio process was launched and no native Godot PCM byte equality is claimed. The recorded reference0992 DT11 shot exists in source but actual shotgun.fire explicitly uses _mechanisms.blast and bypasses that route.

PCG32 algorithm by M.E. O'Neill, pcg-random.org, Apache License2.0. Godot Engine RandomPCG float sampling implementation reference: https://github.com/godotengine/godot/blob/4.6.2-stable/core/math/random_pcg.h and thirdparty/misc/pcg.cpp. Godot Engine contributors, MIT. This tool reimplements the source algorithm and retains its source/provenance references; it does not extract or alter any historical build.
