# Pose lifetime contract v1 — root-owned additive ports

`Session.GetConnectionIdentity(actor)` returns an opaque server-owned local object for exactly one admitted connection incarnation, or null if not connected. Successful legacy Join rotates it even when a reserved Member is reused; prepared Join constructs a fresh Member/identity. The token is stable during that incarnation, is not numeric, is not transmitted or derived from client IDs, and is checked by object identity together with the exact Session object/session/epoch/canonical actor. An old identity must never become valid merely because the same actor name reconnects. It attests connection incarnation only, not physical tracking, health/life or remote pose authority.

`UnityPlayerDriver.PoseSourceIdentity` is an opaque component-owned local source-lifetime identity. `PoseSourceInvalidated` fires synchronously on its main lane after rotation for driver enable/disable, lifecycle rebinding, desktop/XR source switch, application suspension and explicit XR lifecycle invalidation. Each subscriber is called independently; a failing presentation subscriber is logged and cannot prevent other invalidations. Subscribe/unsubscribe in the presentation owner; hide/revoke without waiting for another Pump. A callback captured by an obsolete provider cannot hide or revoke a replacement. The ordinary gameplay `Paused` setter does not rotate this identity: paused actions and still-live physical head/hand display remain distinct.

These additive ports do not make caller-supplied Connection/Tracking numbers trustworthy. A provider binds both actual opaque tokens when created, verifies the live pair before each full presentation and handles source invalidation immediately. Compatibility APIs lacking initial attestation must fail closed for native activation. Neutral test adapters may label quarantined snapshots explicitly, never promote them as production.

Physical XR pose-loss generation, live per-life authority, post-successful-motor scheduling, full recenter/collider policy, accepted rig/export/pivot receipts and remote authenticated pose data remain separate required bindings. Native InputDevices tracking checks alone can miss events between samples; do not claim these new lifetime ports close that gap. The native pilot remains quarantined. Source head/hands, collider and root transforms are never written by presentation. Dispose is idempotent, terminal to its binding and has no replacement authority.

Root evidence: phase15/session-identity-validation.json has12 actual Session join/disconnect/same-actor/remap assertions. Driver ports compile in the root native World capture, but event ordering and actual Avatar consumer execution require new native gates and fresh independent review. This contract creates no M1 or production approval.
