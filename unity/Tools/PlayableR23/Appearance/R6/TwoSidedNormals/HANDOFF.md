# Source two-sided neck normal binding fixed

CPU implementation released. Four changed/new paths and hashes in `changed-paths.json`: existing Appearance runtime shader selection; existing R23AppearanceSpecular.shader face check; new Resources/R23AppearanceDoubleSided.shader+meta. No mesh,palette,roughness,metallic,light/camera/Filmic/handpose/Root/World changes. All original115 payloads, accepted source-neutral preview code/data and color-domain helper remain byte-identical.

The neck is **not white albedo**. Original Stacy AvatarHead neck and face share primitive/material2 `Warm skin.042`: baseColorFactor(.587016,.263273,.170645),metal0,rough.55,doubleSided=true; no texture,COLOR_0 or material extensions. Live153908 receipt correctly binds encoded(.79,.55,.45). Source apply_style clears material_override. Changing neck tint would conceal the real issue.

`neck-ray-proof.json` records exact original GLB/native image hashes and six source-camera ray hits. Native white pixel(480,625) reaches the BACK of that source primitive with interpolated N.z=-.9997, while face pixel(480,535) reaches the FRONT with N.z=+.9976. Other clipped neck pixels are backfaces too. The mesh's neck winding/normal orientation is authored inward; source double-sided rendering intentionally handles it. Geometry/normals were transported faithfully and must not be rewritten just for the picture.

Godot Compatibility [cull_disabled enables DO_SIDE_CHECK](https://github.com/godotengine/godot/blob/4.5/drivers/gles3/storage/material_storage.cpp#L1272), and [fragment shading flips the normal on !gl_FrontFacing](https://github.com/godotengine/godot/blob/4.5/drivers/gles3/shaders/scene.glsl#L1690). Existing Unity URP Lit CullOff merely renders both sides without that normal flip. Its inward neck normal receives the wrong key/specular response, producing the localized white band despite correct color.

Fix: source doubleSided=true/specularFactor1 materials use a small Appearance-owned **stock installed URP17.6 Lit wrapper**. It preserves Lit properties/materials and calls unchanged LitPassFragment. Only backfaces negate geometric N; tangent.w also negates so stock cross(N,T)*sign preserves the original tangent and binormal, matching Godot's normal-map convention. Backface vertex SH/additional-vertex-light values are refreshed. Frontfaces pass straight through. UniversalForwardOnly avoids falling through an uncorrected GBuffer pass; stock ShadowCaster/DepthOnly remain. Target3.5/stereo/instancing/URP variants retained. Non-double-sided regular materials still use unchanged URP Lit. Existing source-specular shader gets the same gated per-face normal handling, without changing its front-face BRDF or material factors.

This is a source material sidedness binding fix across applicable Appearance materials, not a Stacy-specific recolor. Source shape,all115 manifests/textures and the accepted Gamma factor encoding remain unchanged. URI/key-light/capture values unchanged. General radiometry/Filmic limitations remain; the corrective normal direction is the demonstrated difference here.
