# Launch-platform references

Viewed November 1, 2026, for behavior and original procedural modeling only. No original artwork/model/texture is copied into ASHFALL.

- [RadFox VR University: Beginner's Tutorial, Part 1](https://www.youtube.com/watch?v=q1gr_8lfWC8): browser film inspection of the elevated dark metal platform, open arena-facing edge, triangular structural braces; Flying on platform/hotdrop and Pod flying chapters. Gameplay B-roll differs between timestamps; do not infer exact model dimensions from it.
- [John Hermanowski: original POPULATION:ONE Drop-POD Breakdown](https://digiherm.artstation.com/projects/Qr6lPx): primary artist reference for broad angular shell, compact cabin, low-poly/trim-sheet approach, Quest optimization and opening concept. Original work remains all-rights-reserved and is reference only.
- [Drop Pods reference](https://population-one-vr.fandom.com/wiki/Drop_Pods): secondary cross-check that pods are optional, powered travel is bounded and players can eject early. User's requested team/corner/random-destination behavior governs ASHFALL implementation.
- [Official vertical-combat overview](https://www.populationonevr.com/): climbing, flying and building remain the existing ASHFALL movement systems after leaving the launch structure.

ASHFALL platform/pod meshes, materials and control implementation are original code-created work under the project Apache-2.0 license. Exact source-platform assignment is only claimed when backed by inspected map data; otherwise stations are explicitly a new reconstruction.
