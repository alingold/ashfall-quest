# CYBER BIRD R4 — completed isolated candidate

[Launch VR](CYBER-BIRD-R4/Launch-VR.cmd) · [Launch desktop](CYBER-BIRD-R4/Launch-Desktop.cmd) · [Friend ZIP](CYBER-BIRD-R4-Friends.zip) · [Instructions](CYBER-BIRD-R4/README.txt) · [Change manifest](CYBER-BIRD-R4/CHANGE-MANIFEST.txt)

The multiplayer lobby is now **an in-map warmup**, separate from the main menu. HOST / ENTER WARMUP and JOIN / ENTER WARMUP put players together in the sheltered Night Terminal. Explore, climb, fly, collect equipment, build and talk without player damage or zone/scoring. **Pause > SESSION > START MATCH** works for a solo host and resets everyone to match spawns. The host rules panel also has START MATCH. Match end, time/kill cap or END MATCH returns everyone to grouped warmup spawns in the same loaded city. LEAVE SESSION / MAIN MENU unloads the selectable map. The common campaign framework remains the accepted base.

Stamina has its own clear runner icon, gold row and percentage below health. Host rule rows have guide lines to their +/- buttons. Presets retain Cyber Bird. Voice is opt-in under **Pause > SESSION > MICROPHONE**, defaults OFF and is audible within about 40 metres; listening and individual mute controls are included. Generated audio crossed real ENet peers; actual microphones/acoustics/OS permissions still need testing. No local microphone monitoring or recordings are written.

All earlier R2/R3 changes remain: Argon's three skins, thin-wall hand contacts, floating stairs, denser city and giant birds, backpack GRIP-to-equip/TRIGGER-to-drop, upright blade icons, square zone, one-foot world outline and compact team HUD. Existing weapon handling/data/reloads, inventory provider, builder and calibration/initialization implementations are pinned. R4 retains R3 player height, locomotion and bindings. New movement packet epoch/spawn identifiers prevent delayed pre-respawn poses from replacing fresh server spawns.

**Lag investigation:** old R3 play logs were inspected read-only. They do not establish the exact PC/compositor slowdown. R4 fixes the retained selectable map and transient resources. Six native city entry/exit cycles freed city/environment references and held menu nodes at 10102, resources at 883, and reported video memory at 3494815056 bytes through the final cycle. Those are XR-OFF renderer measurements, not headset frame-rate claims.
